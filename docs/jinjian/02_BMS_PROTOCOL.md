# 金箭 BMS 通讯协议

> 范围：金箭 BMS 设备的寄存器地图、Modbus 指令、应答解析、单位与 CRC 示例。
> 采集/上报过程与上报消息清单见 `03_BMS_COLLECTION_REPORT.md`。

---

## 1. 物理层（485）

| 参数 | 值 |
|---|---|
| 总线 | RS-485 |
| 波特率 | **9600** |
| 数据位/校验/停止位 | 8 / N / 1 |
| 帧格式 | Modbus RTU |

> 金箭中控的其它通道不要与 BMS 485 混用：4G 为 115200、蓝牙为 230400。

---

## 2. 常用指令

### 2.1 读寄存器（03）

```
01 03 <address 2B BE> <num 2B BE> <CRC16 LE>
```

### 2.2 读开关量（01）

```
01 01 <address 2B BE> <num 2B BE> <CRC16 LE>
```

### 2.3 写单个寄存器（06）

```
01 06 <address 2B BE> <value 2B, 16 位有符号补码> <CRC16 LE>
```

### 2.4 写单个开关量（05）

```
01 05 <address 2B BE> <FF00|0000> <CRC16 LE>
```

### 2.5 应答结构

- 读寄存器：`01 03 <byteCount 1B> <data> <CRC>`
- 读开关量：`01 01 <byteCount 1B> <bit 数据> <CRC>`
- 写：`01 06/05 <address> <value> <CRC>`
- 异常：功能码 `>0x80`（`原功能码-0x80`，异常码 01/02/03/06）。

## 3. 寄存器地图

### 3.1 基础信息（03 地址 0；周期只读 0–8，详情读 0–32）

| 寄存器 | 名称 | 单位/说明 |
|---|---|---|
| 0 | 总电压 | 0.01V（÷100 = V） |
| 1 | 电芯串数 | 决定单体电压读取数量 |
| 2 | SOC | 0–100，需 clamp |
| 3 | 容量 | 原始值 |
| 4 | 短路保护 | 模拟量块；保护状态另走开关量 4 |
| 5 | 充电电流 | ÷100 = A；符号=充/放电 |
| 6 | 电池温度 2 | 与 7 取 max 为最高温度 |
| 7 | 电池温度 1 | 同上 |
| 8 | 板温 | 模拟量块里是板温，勿与保护开关量 reg8 混用 |
| 9–32 | 单体 1–24 电压 | 数量由 reg1 决定 |

字段映射：

`reg0=totalVoltage、reg1=cellCount、reg2=soc、reg3=capacity、reg5=chargeCurrent(÷100=A)、reg6=temperatureBattery2、reg7=temperatureBattery1、reg8=temperatureBoard、reg103=batteryType、reg104=useCycleCount、reg110=balanceStatus、reg113=nominalCapacity、reg9..=cellVoltages`。

### 3.2 电池状态（03 地址 103，num=11）

| 寄存器 | 名称 |
|---|---|
| 103 | 电池类型 |
| 104 | 循环次数 |
| 110 | 均衡状态 |
| 113 | 标称容量 |

### 3.3 保护开关量（01 地址 4，num=5）

| 地址 | 含义 |
|---|---|
| 4 | 短路保护 |
| 5 | 过温充电保护 |
| 6 | 过温放电保护 |
| 7 | 低温充电保护 |
| 8 | 低温放电保护 |

### 3.4 快充

| 项 | 功能码 | 地址 |
|---|---|---|
| 快充状态 | 01 | 63 |
| 结束快充 | 05 | 64（写 `FF00`） |

### 3.5 充电设置（寄存器）

| 寄存器 | 含义 | 范围 |
|---|---|---|
| 1089 | 充电时间 | 0–120 分钟 |
| 1090 | 目标 SOC | 0–100 |

### 3.6 版本/PN

| 内容 | 功能码 | 地址 | num |
|---|---|---|---|
| 版本 | 03 | 1016 | 2 |
| PN | 03 | 1000 | 8（逐寄存器 ASCII） |

版本解析：`formatSoftwareAndHardwareVersion(a,b)` → `a高.a低.b高.b低`。

## 4. 响应解析规则

1. key3+AES-128-ECB 解密（BLE 通道）或按 485/4G 链路取明文；
2. 校验 CRC16（LE）；
3. 功能码 `>0x80` → 异常；
4. 读寄存器：每 2 字节 16 位大端转有符号（`>0x7FFF` 减 `0x10000`）；
5. 读开关量：LSB=bit0 逐位展开。

### 4.1 示例

响应 `01 03 14 0E1C 0004 0046 0032 0000 0005 0019 001A 0018 ...`：

reg0=`0E1C`=3612（总压 raw）、reg1=4（串数）、reg2=70（SOC）、reg3=50、reg5=5、reg6=25、reg7=26、reg8=24（板温）。

> 周期轮询读 0–8（num=9）；详情读 0–32；两者不同步时以周期数据为准。

## 5. 常用命令与 CRC 示例（明文）

| 用途 | 命令 | CRC |
|---|---|---|
| 周期读 0–8 | `01 03 0000 0009` | `85CC` |
| 详情读 0–32 | `01 03 0000 0021` | `85D2` |
| 读 103–113 | `01 03 0067 000B` | `B5D2` |
| 读版本 | `01 03 03F8 0002` | `45BE` |
| 读 PN | `01 03 03E8 0008` | `C47C` |
| 读快充 | `01 01 003F 0001` | `CDC6` |
| 读充电设置 | `01 03 0441 0002` | `952F` |
| 写充电时间 60 | `01 06 0441 003C` | `D8FF` |
| 写目标 SOC 90 | `01 06 0442 005A` | `A8D5` |
| 结束快充 | `01 05 0040 FF00` | `8D EE` |
| 读保护开关量 | `01 01 0004 0005` | `BDC8` |

> `结束快充` 一行按标准 Modbus CRC 计算应为 `8D EE`，以从机实际校验为准。
